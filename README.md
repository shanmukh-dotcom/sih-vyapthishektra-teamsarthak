## 🚨 The Problem
The agricultural supply chain is structurally broken. 
- **Farmers** lose up to 40% of their potential profits to multi-tiered middlemen and suffer from a severe lack of direct market access.
- **Corporate Buyers** (FMCGs, Retailers, Processors) struggle with fragmented supply, inconsistent quality, and opaque pricing.
- **Logistics** are highly inefficient and disconnected, leading to massive post-harvest losses before produce even reaches the consumer.

## ✨ The Solution
**Vyapti Kshetra** is a next-generation Agritech marketplace. 
We provide a transparent, AI-driven ecosystem that connects Farmers and Farmer Producer Organizations (FPOs) directly with Corporate Buyers, FMCG companies, and retail chains.

By replacing the traditional *Mandi* system with an intelligent digital infrastructure, we ensure **fair prices for farmers** and **reliable, high-quality, traceable supply for buyers**.

---

## 🚀 Key Features

### 🧑‍🌾 For Farmers & FPOs (Mobile-First)
- **Direct Market Access:** Bypass intermediaries and sell directly to verified corporate buyers and enterprises.
- **AI Fair Price Predictor:** Real-time, localized market price intelligence ensuring farmers never undersell their hard work.
- **Universal Multilingual Support:** Instant, native auto-translation of the entire platform into regional languages for zero-friction adoption.
- **Automated Logistics Matchmaking:** Simplified tracking and dispatch management right from the farm gate.

### 🏢 For Corporate Buyers (Enterprise SaaS)
- **AI Supply Matchmaking:** Post a requirement (e.g., "12,000kg Grade A Tomatoes") and our AI instantly ranks the best FPOs based on distance, quality score, and price.
- **Live Bidding & Negotiation:** Integrated live-chat and counter-offer system with automated escrow execution.
- **Supply Chain Visibility:** Real-time GPS tracking and transit milestone monitoring.
- **Actionable Analytics:** Comprehensive dashboard tracking procurement spending, estimated savings, and historical supplier performance.

## 💻 Tech Stack
- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Turbopack)
- **Styling & UI:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** React Context API (Simulated Global State)
- **Deployment:** [Vercel](https://vercel.com)
- **Translation:** Google Translate API Integration

## 🛠️ Getting Started

To run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/shanmukh-dotcom/sih-vyapthishektra-teamsarthak.git

# 2. Navigate into the frontend directory
cd frontend

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
